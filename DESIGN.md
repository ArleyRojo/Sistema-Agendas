## Brand & Style

This design system embodies a modern, high-clarity productivity environment engineered for managing operational tasks and binding commitments. The visual identity projects reliability, calm focus, and deliberate structure. It targets professionals, project managers, and executives who balance tight timelines and non-negotiable commitments.

The aesthetic blends **Modern Corporate** with **Architectural Minimalism**:
- Immaculate white canvas surfaces accented by tailored aerospace-inspired blues.
- Razor-sharp information density without clutter or cognitive overload.
- Purposeful visual feedback: state transformations are crisp, definitive, and reassuring.
- Semantic badge systems that communicate urgency and completion instantaneously.

## Colors

The palette establishes an ultra-clean workspace with deliberate focal points, utilizing functional tinting and strict contrast standards.

### Core Canvas & Structural Neutrals
- **Background Canvas**: `#FFFFFF` (Primary Surface), `#F8FAFC` (Secondary Canvas / Shell).
- **Surface Layer 2**: `#F1F5F9` (Dividers, Inactive Wells, Input Backdrops).
- **Border Definers**: `#E2E8F0` (Default Card Outline), `#CBD5E1` (Hover / Interactive Borders).
- **Typography Neutrals**: `#0F172A` (Primary Text / High Contrast), `#475569` (Secondary Descriptive Text), `#94A3B8` (Muted / Metadata / Placeholders).

### Brand & Interactive Accents
- **Primary Action (Sky 700)**: `#0284C7` (Dominant controls, focused states, primary buttons).
- **Interactive Blue (Blue 500)**: `#3B82F6` (Active tabs, commitment indicators, link elements).

## Typography

The typographic pairing balances crisp navigational hierarchy with dense data legibility:
- **Plus Jakarta Sans** governs major headings, modal titles, and board metrics, infusing modern geometric character without excessive ornamentation.
- **Inter** handles high-volume task descriptions, commitment logs, tabular rows, and inputs, providing flawless neutral legibility.
- **JetBrains Mono** is reserved exclusively for the Test Runner tab, telemetry statistics, timestamps, and test case signatures.

### Application Rules
- Use `label-xs` in uppercase for status, priority pills, and table headers with `0.04em` tracking.
- Apply tabular numerals (`font-feature-settings: "tnum"`) across counters, time intervals, and test metrics.

## Layout & Spacing

The productivity suite operates on an 8pt structural baseline grid (with a secondary 4pt micro-alignment step).

### Structural Framework
- **Master Grid**: 12-column layout on desktop (`1280px+`), collapsing to 6 columns on tablet (`768px - 1023px`), and a single dynamic fluid column on mobile (`< 768px`).
- **Application Shell**: Sticky horizontal primary navigation header (height: 64px) alongside a collapsible dual-mode secondary navigation sidebar (260px expanded, 68px collapsed).
- **Workspace Canvas**: Maximum container constraint at `1440px` with horizontal centering.

### Breakpoint Matrix
- **Mobile (< 768px)**: Edge margins at `1rem`. Dual column modules (Tasks vs. Commitments) stack vertically into unified segmented switchers.
- **Tablet (768px - 1023px)**: Edge margins at `1.5rem`. Side navigation condenses into icon triggers; two-column grid ratio defaults to 50/50.
- **Desktop (1024px+)**: Edge margins at `2.5rem`. Supports concurrent multi-pane workflow (Agenda List + Detail Inspector + TDD Runner dock).

## Elevation & Depth

This system avoids heavy, muddy drop shadows, relying instead on **low-contrast architectural outlines** paired with subtle ambient diffusion.

### Elevation Hierarchy
- **Level 0 (Flat Canvas)**: `#FFFFFF` or `#F8FAFC` background with no shadow. Structural separation is maintained strictly via `1px solid #E2E8F0`.
- **Level 1 (Cards & Data Panels)**: `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)` with `border: 1px solid #E2E8F0`.
- **Level 2 (Hover States & Dropdown Popovers)**: `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)` with `border: 1px solid #CBD5E1`.
- **Level 3 (Interactive Modals & Slide-over Sheets)**: `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)` with `border: 1px solid #E2E8F0`.
- **Backdrop Scrim**: `rgba(15, 23, 42, 0.35)` with an ultra-fine `backdrop-filter: blur(4px)`.

## Shapes

The interface balances sharp productivity efficiency with modern tactility using balanced corners (`0.5rem` / `8px` baseline).

### Corner Geometry Tokens
- **Micro (Inputs, Checkboxes, Micro-pills)**: `0.375rem` (6px).
- **Default (Standard Buttons, Data Cards, Form Fields)**: `0.5rem` (8px).
- **Containers (Panels, Suite Modules, Modals)**: `0.75rem` (12px).
- **Status / Priority Badges**: `9999px` (Full Pill) for clear visual segregation from rectilinear content containers.

## Components

### Buttons
- **Primary**: Solid background `#0284C7`, text `#FFFFFF`, corner radius `8px`, height `40px` (desktop), `44px` (mobile). Hover: `#0369A1`. Focus: `2px` ring `#38BDF8` with `2px` offset.
- **Secondary / Ghost**: Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#0F172A`. Hover: Background `#F8FAFC`, border `#CBD5E1`.
- **Subtle Action**: Background `#E0F2FE`, text `#0284C7`, no border. Hover: Background `#BAE6FD`.

### Priority & Status Badges
- Displayed using pill geometry with uppercase `label-xs` typography, accompanied by a `6px` solid status circle dot aligned to the left of the label.
- Micro-padding: `2px 8px` on height `22px`.
- High contrast borders: Each badge possesses an intentional `1px` matched tint border to prevent bleed into white card surfaces.

### Cards & Commitment Tiles
- White canvas (`#FFFFFF`), `1px solid #E2E8F0` border, `16px` internal padding.
- Left-edge indicator stripe (`3px`) color-coded to commitment urgency or status.
- Hover transition: Border shifts to `#93C5FD` with a subtle `translateY(-1px)` translation.

### Interactive Modals (Creation & Scheduling)
- Fixed center overlay or sheet; header with clear category icon, title in `headline-sm`, and close affordance.
- Form body divided into two-column fields on desktop: Title, Due Date & Time, Assigned Owner, Priority dropdown, and Commitment scope notes.
- Footer with explicit right-aligned actions: Secondary "Cancelar" and Primary "Guardar Tarea / Agendar Compromiso".

### Form Controls & Inputs
- Inputs feature `#FFFFFF` background, `1px solid #CBD5E1` border, `8px` radius, and `14px` typography.
- Active focus state: `border-color: #0284C7`, `box-shadow: 0 0 0 3px rgba(2, 132, 199, 0.15)`.

### Checkboxes & Action Radios
- Rounded `4px` squares with `#E2E8F0` border.
- On checked: Smooth `#0284C7` fill with white checkmark icon, accompanied by optional strikethrough transition on associated task title.

### TDD Test Runner Panel
- Monospaced console well styled in `#0F172A` deep navy or crisp `#F8FAFC` inverted light diagnostic view.
- Header showing `100% PASS` badge (`#15803D` text on `#DCFCE7`).
- Structured spec table displaying test suite names, execution times (ms), status checks (`✓ PASS`), and reactive re-run trigger button.
